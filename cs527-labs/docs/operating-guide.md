# Operating Guide

## Prerequisites

- g++ with C++17 support
- make
- Linux / macOS / WSL (tested on Linux)

## Building a Lab

```bash
cd lab1   # or lab2, lab3, lab4, lab5
make
```

This produces the executable `./simulator`.

## Running

### Lab 1

```bash
./simulator <program.txt>
```

- Compiles `program.txt` → `program.byte`
- Expects a `data.byte` in the current directory (or creates a zeroed one)
- Runs the program and writes final data memory back to `data.byte` (and optionally `data.out`)

### Lab 2 / Lab 3

```bash
./simulator <program.txt> [data.byte]
```

If `data.byte` is omitted a zero-filled data memory is used.

### Lab 4 / Lab 5 (multi-process + OS)

```bash
./simulator
```

You get an interactive shell:

```
$ prog1.txt data1.byte
$ prog2.txt data2.byte
$ exit
```

The OS schedules the tasks on the available processors using time-slicing.

## Expected Output Files

- `program.byte` – generated bytecode (hex, 4 bytes per line)
- `data.byte` / `data.out` – final data memory
- `log.txt` (Lab 4+) – Print instruction output

## Cleaning

```bash
make clean
```
